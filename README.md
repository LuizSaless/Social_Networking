## Curso de Ruby Avançado da Digital Innovation One.

### Ruby on rails: Montando uma rede social

• Desenvolvimento de aplicação web com Ruby on Rails, seguindo o padrão MVC  
• Implementação de funcionalidades como cadastro e autenticação de usuários, criação de perfis e interações entre usuários  
• Modelagem de dados e persistência utilizando ActiveRecord e PostgreSQL  
• Criação de rotas RESTful e controllers para gerenciamento de recursos  
• Versionamento de código com Git e GitHub
