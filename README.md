# 📌 Ruby on rails: Montando uma rede social
---

## 💡 Sobre o Projeto

O **Social Networking** é uma aplicação web que simula uma rede social básica, onde usuários podem se cadastrar, fazer login, criar posts, seguir outros usuários, curtir posts, comentar e visualizar timelines. O projeto foi desenvolvido como parte de um curso prático, com foco em **CRUDs, autenticação, relacionamentos e interface responsiva**.

---

## 🚀 Funcionalidades

### 👨‍💼 Área Administrador
- Dashboard privado para administradores
- Gerenciamento completo de administradores (CRUD)

### 👤 Usuários
- Cadastro de usuário
- Login e autenticação
- Área privada do usuário
- Timeline com posts de usuários seguidos

### 📝 Interações Sociais
- Criação de posts
- Curtir / Descurtir 
- Seguir / Deixar de seguir usuários
- Criar e excluir comentários
- Contagem de comentários e curtidas
